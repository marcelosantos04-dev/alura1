# 🎨 Monalisa Interativa

Uma arte interativa e responsiva da famosa pintura Monalisa de Leonardo da Vinci, com olhos que acompanham o movimento do cursor do mouse.

## ✨ Características

- **Olhos Interativos**: Os olhos da Monalisa seguem o movimento do seu cursor/toque
- **Cores Originais**: Utiliza as cores originais da obra de Leonardo da Vinci
- **Responsivo**: Funciona perfeitamente em desktop, tablet e mobile
- **Código Limpo**: Todo o código está contido em arquivos HTML, CSS e JavaScript puros
- **Animações Suaves**: Transições suaves e efeitos visuais agradáveis

## 📁 Arquivos do Projeto

- `index.html` - Estrutura SVG da Monalisa com elementos interativos
- `style.css` - Estilos e animações
- `script.js` - Lógica interativa dos olhos que seguem o cursor
- `README.md` - Este arquivo

## 🚀 Como Usar

1. Clone o repositório ou baixe os arquivos
2. Abra o arquivo `index.html` em seu navegador
3. Mova o cursor sobre a imagem para ver os olhos acompanharem seu movimento

## 💡 Cores Utilizadas

- **Pele**: #F4A460, #D2691E (tons de terra quentes)
- **Cabelo**: #3D2817 (marrom escuro)
- **Olhos**: #FFFFFF com #2F1B0C (branco e marrom profundo)
- **Céu**: #87CEEB para #E0F6FF (azul claro)
- **Corpo**: #8B4513 (marrom sela)
- **Paisagem**: #8B7355 (tons terrosos)

## 🎯 Como Funciona a Interatividade

O arquivo `script.js` implementa:

1. **Cálculo de Ângulo**: Usa trigonometria para determinar a direção do cursor
2. **Movimento das Pupilas**: As pupilas se movem em um raio limitado (5px) em direção ao cursor
3. **Suporte a Touch**: Funciona também em dispositivos com tela tátil
4. **Reset Automático**: Quando o mouse sai da tela, os olhos retornam ao centro

## 📱 Responsividade

O projeto é totalmente responsivo e se adapta a qualquer tamanho de tela:

- Desktop
- Tablet
- Mobile (com suporte a touch)
